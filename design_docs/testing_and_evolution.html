2. Current RAG Tests

BoundaryWhat is verified
Context builder[CV#] source IDs, wage formatting, evidence inclusion, and removal of missing nan values.
Ollama clientModel discovery, non-streaming chat payload, connection-error mapping, and missing-model errors.
RAG serviceRetrieval occurs before generation, retrieved evidence enters the prompt, and generation is skipped when no source survives constraints.
CLI parser--method rag, generator model, and Ollama URL options.
Existing retrieval testsTF-IDF ranking, embedding ranking, profile construction, text helpers, and vector normalization.

3. Retrieval Evaluation Remains Separate

flowchart LR P[(evaluation profiles)] --> T[TF-IDF] P --> E[Embeddings] T --> M1[Recall at K MRR NDCG] E --> M2[Recall at K MRR NDCG] M1 --> C[Compare retrieval] M2 --> C

RAG does not replace these metrics because the generator does not determine which careers are retrieved.

5. Failure Analysis

flowchart TD BAD[Bad RAG answer] --> Q{Where did failure originate} Q --> RET[Retrieval failure] Q --> CTX[Context projection omitted evidence] Q --> GEN[Generator ignored evidence] Q --> DATA[Source dataset limitation] RET --> FIX1[Tune or hybridize retrieval] CTX --> FIX2[Improve evidence projection] GEN --> FIX3[Prompt or model evaluation] DATA --> FIX4[Improve data coverage]

6. Roadmap

flowchart LR V1[V1 TF-IDF] --> V2[V2 Sentence Embeddings] V2 --> V3[V3 Local RAG] V3 --> V4[V4 Hybrid retrieval] V4 --> V5[V5 Automated grounding evaluation] V5 --> V6[V6 Feedback reranking and location-aware wages]

7. Release Checklist

  • Run python -m pytest -q.
  • Compile Python modules.
  • Validate every Mermaid diagram and local design-doc link.
  • Verify raw data, model artifacts, .venv, and .git are not included in release ZIPs.
  • Manually smoke-test RAG against a running local Ollama model before a tagged release.
