Purpose

These documents describe CareerVector v0.3 as an end-to-end retrieval and RAG application. The design keeps data preparation, lexical retrieval, semantic retrieval, evidence construction, local generation, presentation, and evaluation as separate concerns.

Design Principles

  • Local-first: no paid inference API is required.
  • Retrieval before generation: RAG does not let the LLM choose careers from unconstrained memory.
  • Grounded evidence: generated factual claims are prompted to cite [CV#] evidence blocks.
  • Inspectable: the UI shows the generated answer and the retrieved evidence cards.
  • Comparable: TF-IDF and embedding retrieval operate over the same processed occupation corpus.
  • Testable boundaries: Ollama is behind a small HTTP client that can be mocked in unit tests.
